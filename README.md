# 🎟️ Biletcik.com — Event Ticketing Platform

> Online ticketing for concerts, theatre, cinema, festivals and more across Cyprus.

🔗 **Live:** [biletcik.com](https://biletcik.com)

![Biletcik](biletcik.jpg)

Biletcik is an event‑discovery and ticketing platform with a clean, modern interface — browse by category and city, explore featured events, and buy tickets online.

> ℹ️ This is a **showcase repository** — documentation and screenshots only. The source code is private.

---

## ✨ Features

- 🎭 **Category browsing** — concerts, theatre, cinema, stand‑up, festivals, nightlife, sports, kids & family.
- 📍 **City / venue filtering** and a featured‑events carousel.
- 🔎 **Search** across events, artists and venues.
- 🎫 **Online ticket purchase** with a smooth checkout flow.
- 📱 Responsive, mobile‑first design.

---

## 🛠️ Tech stack
**PHP** · **JavaScript** · **MySQL**.
